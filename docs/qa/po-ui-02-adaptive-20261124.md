# PO-UI-02 — 폴더블·태블릿·큰 글꼴 접근성

- 현재 창 폭과 fontScale 기준으로 홈 다음 일정/브리핑, 캘린더와 선택일 목록을 2열 배치(폭 800dp 이상 및 유효 폭 760dp 이상). 좁은 창·큰 글씨는 세로로 유지하고 기존 색상/폰트/디자인 토큰 유지.
- 제목 장식 이미지가 글자를 압박하는 창에서는 장식 숨김. 큰 글씨에서 목록 제목 줄 수 제한 완화, 탭 높이 보정, 좁은 창 대화상자 버튼 세로 배치, 달력 터치/입력 접근 유지.
- 앱 방향 고정 해제. QuickEntryActivity는 화면 크기/방향 변경을 기존 View에서 처리하고 창 폭 최대 400dp 유지, 측정 시 최신 창 크기 반영, IME 전체화면 추출 모드 방지. 동일 density 화면 크기 변경에서 작성 중인 텍스트 보존 목표. 프로세스 재시작/밀도·폰트 설정 변경 시 복원은 보장하지 않음.
- Node adaptiveLayout 경계 및 코드 경로, Android 구성 변경 콜백 회귀 추가. 최종 QA 캡처에 넓은 주간 캘린더/작성 중 텍스트/동일 밀도의 실시간 좁은 창 변경 후 텍스트·저장 버튼 검증 추가.
- 실제 갤럭시 폴더블 힌지, 밀도 변화, TalkBack 읽기 순서, 물리 태블릿 및 키보드 검증은 실기기 확인 필요. 캡처 스크립트 추가는 실제 스크린샷 생성 성공이 아님.
- 선행 #90~95 병합 후 최신 main 통합 및 전체 Android QA 1회. Google Play/Firebase 배포 없음.
