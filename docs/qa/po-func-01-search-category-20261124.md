# PO-FUNC-01 — 전체 일정 검색·카테고리 (2026-11-24)

## 구현
- 캘린더 → 전체 일정 검색. 현재 저장된 원본 일정 전체를 TanStack Query 기존 로컬 조회로 사용. 제목·장소·메모 및 카테고리명 검색, 한글 Unicode NFKC·영문 대소문자·공백 정규화, 여러 단어 AND 조건. 원문/인증 정보/회의 URL은 별도 검색 대상에 추가하지 않음. 모든 검색은 기기 메모리에서 처리하고 서버 전송/검색 이력 저장 없음.
- 기본 고정 분류 업무·개인·가족·건강·학습·기타, 미분류(null) 및 전체 필터. 자동 분류 없음. 빠른 입력(텍스트·음성·알림 후보)과 일정 상세에서 명시적으로 선택·변경 가능. 사용자 정의 분류와 복수 태그는 이번 범위 아님.
- 검색 결과 시작일 최신순, 년도 포함, 반복 일정 원본 기준일 한 건 표시. 상세 이동은 기존 ID 경로. FlatList 가상화, 입력 지연 중 검색 중 표시, 실패 재조회, 초기화 및 결과 없음 상태. 캘린더 월/일 이동과 알림 및 반복 규칙 유지.
- SQLite schema 2→3 nullable category 열 추가; 1→3 순차 기존 마이그레이션 유지. 기존 일정 ID, 날짜, 반복·알림, 메모 보존. 네이티브 브리지·TS 변환·백업 v1에 optional category 포함. 과거 백업은 미분류, 신규 일반/암호화 백업은 카테고리 보존. 중복 ID는 기존 일정 우선. 기존 설치된 구버전 앱에서 새 카테고리를 지원한다고 보장하지 않음.
- 개인정보처리방침 두 복사본 및 릴리스 문구 동기화. Play/Firebase 배포나 사용자 데이터 자동 수정 없음.

## 검증
- Kotlin: 고정 ID/유효하지 않은 입력 차단. Android API29 기존 백업 선별 QA에 v1/v2→v3 SQL migration, 브리지/저장/복원/오류 입력 기존 데이터 보존 테스트 추가. 최종 3환경 QA 목록에도 포함.
- Node: 전체 검색, 영문/한글·정규화, AND 필터, 원문/회의 URL 비검색, 반복 원본 중복 방지, 카테고리 및 v1 백업 왕복/변조/비호환 값 검증. 기존 회귀 유지.
- 실제 폴더블·태블릿·TalkBack·긴 일정 목록 UI/성능 및 화면 캡처는 최종 실기기·전체 QA에서 확인.
