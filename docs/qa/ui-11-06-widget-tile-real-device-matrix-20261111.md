## 2. 실제 삼성 One UI 기기 QA (별도, 현재 미검증)

기기 모델, One UI/Android 버전, 글꼴 배율, 앱 Git SHA 및 APK 버전 코드를 기록하고 다음 항목을 촬영/확인합니다.

1. 홈 화면 위젯 추가: 다음 일정 위젯·오늘 일정 위젯 각각 수동 추가 및 Android 위젯 고정 요청 처리, 0/1/3건 표시와 실데이터 대조.
2. 위젯 크기 변경: 최소·기본·확대 및 가로/세로 화면 회전, 긴 제목·매월·매년 반복·종일·종료시각, 라이트/다크 및 글꼴 100/130/160/200%.
3. 클릭 행동: 위젯의 일정 행 → 정확한 일정 상세, '텍스트' → 입력 화면, '음성' → 녹음 시작 전 편집 화면. 위젯 없는 상태의 '일정 없음' 클릭 확인.
4. 빠른 설정 타일: 추가/제거·활성화/비활성화, 잠금 화면에서 클릭 후 잠금 해제, 알림/마이크 권한 미승인 상태에서 자동 녹음이나 자동 저장이 발생하지 않는지 확인.
5. 시스템 상태 복구: 재부팅, 시간/시간대 변경, 날짜 변경, 절전 정책과 백그라운드 제한, 알림 권한 철회/재허용 후 위젯·예약 상태를 비교.
6. 사용자 안전: 설치/업데이트 전후 일정 데이터·반복 알림 보존, 민감 알림 접근 동의/철회/보관 기간 별도 확인.

**증빙:** 각 항목의 전·후 캡처, 실제 실행 결과(pass/fail/blocked), 재현 절차, 기기/OS 및 검증 SHA. 실제 기기를 제어하거나 연결한 증거가 없는 한 PASS로 표시 금지.
