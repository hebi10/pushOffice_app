# PO-FUNC-02 — 다중 사전 알림 및 완료 상태 (2026-11-24)

## 기능 범위
- 시작 시간 / 5·10·15·30분 전 / 1·2시간 전 / 1일 전 가운데 1~4개를 선택. 기존 일정은 시작 시간 단일 알림으로 유지. 알림 꺼짐 상태에서도 선택값은 저장. 이미 지난 사전 알림은 신규 예약하지 않음.
- 회차 기준 시각에서 경과 분을 빼는 독립 예약, 각 시점별 PendingIntent URI 및 토큰 분리, 기존 시작 알림/재알림 호환. 재예약/부팅/시간대 변경 시 동일 예약 유지. 늦은 사전 알림은 해당 일정 시작 이후 전달하지 않음. Android exact 권한/절전 정책은 실제 기기 제약에 따름.
- 완료/완료 취소는 최신 DB 행의 별도 명시적 mutation. 완료 시 선택한 알림 설정과 일정 정보는 유지하고 모든 알림·snooze·다음 일정·위젯·아침 브리핑을 제외. 반복 일정의 완료는 **전체 시리즈**, 개별 회차 수정/삭제/완료는 후속 범위. 캘린더는 완료 이전 회차와 원본 기준일 보존, 검색에는 완료 상태 표시. 완료 취소는 미래 회차·알림만 예약. 과거 일정 재활성화 자체는 허용하되 과거 알람 생성 금지.
- SQLite v3→4 (reminderOffsets TEXT DEFAULT '0', completedAt INTEGER nullable), v1/v2→v4 누적 마이그레이션. 기존 예약 fingerprint의 기본값 호환. 일반/암호화 백업 v1의 optional 필드; 기존 파일에는 기본값/미완료 적용.
- Android 빠른 입력 선택, 상세 편집 다중 선택 및 명시적 완료 확인, 목록 완료 표시. 서버 전송/자동 완료/자동 삭제 없음.

## 검증
- Kotlin 선택 범위, 지난 시각, 반복 다음 회차, 기존 fingerprint, 완료 제외, 알림 ID 충돌 방지.
- Android 계측: v3 DB 이전, 실제 AlarmManager/PendingIntent 예약 및 토큰, 복구 receiver, 독립 회차 갱신, 완료 시 전부 무효화·취소·snooze 차단, 완료 취소, 구버전 예약 호환, 완료 백업 복원. 기존 빠른 입력 계측에서 30분 전 선택·저장 확인.
- Node: 선택 제한, 완료 회차 투영, 백업 v1 왕복, UI/네이티브 통합 경계. 실제 장시간 Doze, 알림 권한 변경, 물리 기기 재부팅 및 삼성 실기기 QA는 별도.
