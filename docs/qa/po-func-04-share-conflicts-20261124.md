# PO-FUNC-04 — 공유 텍스트 일정 입력 및 시간 충돌 확인
- Android ACTION_SEND / text/plain 전용 ShareTextActivity. 1~4096자, 제어문자·잘못된 유형·다중 공유 거부. URI, 스트림, 외부 파일 및 자동 링크 열기 없음. 실제 QuickEntryActivity는 non-exported 유지. 편집 가능한 텍스트로 전달 후 명시적 확인·저장. 공유 자체에서 DB/AI 호출 없음.
- 기존 Kotlin 반복 엔진과 제외 회차/완료 상태를 재사용하여 저장 직전 로컬 겹침 확인. 시간 범위는 시작 포함/종료 제외, 종일은 일정 시간대의 다음 자정, 종료 미지정은 시작 시각 point. 반복 제안은 첫 예정 회차부터 30일, 최대 8개 충돌 샘플. 개별 회차 변경은 그 회차만 자기 비교에서 제외, 나머지 시리즈 회차는 포함. 기존 일정 완료·제외 회차는 겹침 대상에서 제거.
- 빠른 입력/상세 수정/회차 수정에서 확인 창에 표시하고 확인 후 저장. 권고 기능이며 확인 이후 다른 일정이 바뀌는 경쟁이나 전 기간 충돌 없음은 보장하지 않음. 큰 목록의 실기기 응답시간은 최종 QA에서 검증.
- JUnit 경계·교차 자정·DST·반복/완료/예외·입력 제한, Android manifest 및 실제 편집창 공유 텍스트 확인과 미저장 검증, Node 경로 회귀. 실제 외부 앱 공유 시트 및 삼성/폴더블 기기 확인은 최종 QA 필요.
- 선행 #90~#93 병합 후 최신 main 정확한 SHA에서 통합 재검증. Play/Firebase 배포 없음.
