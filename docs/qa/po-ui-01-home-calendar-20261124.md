# PO-UI-01 — 홈·캘린더·빠른 입력 사용성
- 홈 후보: 권한·활성 상태·후보를 같은 native snapshot으로 조회. 후보 변경 이벤트(내용 미포함)와 화면 활성 시 갱신, 권한 확인용 15초 제한 조회, 요청 병합 및 비활성/이전 방문 응답 무시. 미확정 후보에 임의 날짜/시간을 표시하지 않음. 전체 후보 인라인 펼침, 오류 재조회, 당겨서 일정/후보 같이 갱신, 중복 검토/거절 버튼 차단.
- 캘린더 월간/주간 선택, 오늘 이동, 주간 이전/다음, 월 경계 전체 7일 조회, 선택 날짜 입력 연결 및 기존 월간/날짜 점/목록 유지. 활성 조회만 수행. 실패 재조회.
- 빠른 입력 예시를 명시적인 오후 표현으로 교체하고 4096자 입력 제한/문자 수 표시. 자동 저장 없음.
- Kotlin 기존 알림 저장/권한 회귀 및 Node 주간 날짜/경로 회귀. 실제 화면과 큰 글꼴은 최종 Android QA에서 확인.
- PR #94 기반. 선행 병합 후 최신 main 통합 검증. Google Play/Firebase 배포 없음.
