# UI-12-02 — 홈·브리핑 정보 위계 및 외부 조회 상태

기준: 2026-11-12 · `hebi10/pushOffice_app` · 분기점 `731a7abe7690d945e80ed575edb2f15d0b981619`.

근거 문서: [UI-12-00 기획/실화면 정밀 비교](https://docs.google.com/document/d/1HMLAr5KKDQ1peNKsfkCTyqFIfptxJG38K3h4B8ry9W8/edit) · [UI-12-01 정합성 참고](https://drive.google.com/drive/folders/1HTpOVlr3rm1H4IVIh16HdBcXRjZ8FvuH).

## 수정 범위

- `app/(tabs)/index.tsx`의 홈 화면만 변경. SQLite/일정 모델/반복·알림 계산/권한·AI 엔진/탭·다크 테마/업로드 정책 변경 없음.
- **다음 일정과 오늘 일정의 중복 감소:** 같은 ID+시각의 일정이 다음 일정 카드에 표시되면 오늘 일정 목록에서는 해당 한 행만 생략. 전체 건수는 그대로 표시하며 카드에 '다음 일정 1건은 위 카드에서 확인하세요.'를 명시. 다음 일정 상세 이동과 캘린더 전체 보기 유지.
- **로컬 AI 요약의 중복 감소:** 오늘 일정 목록에 이미 포함된 '다음 일정' 제목을 AI 입력 프롬프트에 다시 덧붙이지 않음. 일정 불러오기 오류 시 빈 일정을 사실로 요약하지 않도록 오류 문구 제공. 사용자 요청 전 추론 금지·요약 오류 복구 유지.
- **알림 후보 안내:** 민감 정보 사전 고지 문구와 명시적 승인·거절·권한 설정 모달은 보존. 카드 본문을 넓은 행으로 배치하고 '안내·설정' 동작은 아래로 분리하여 좁은 화면 줄바꿈 개선.
- **외부 정보 조건부 조회:** `digestTypes` 선택 여부와 실제 `EXPO_PUBLIC_FUNCTIONS_BASE_URL` 주입 여부를 구분. 기본 미선택이면 설정으로 이동 가능, 서버가 미연결이면 원격 조회를 노출하지 않고 명확하게 안내. 둘 다 충족할 때만 버튼 노출하고 사용자가 직접 눌렀을 때만 원격 호출. 이전 날짜의 반환 데이터를 오늘 데이터로 표시하지 않음.
- 날씨·뉴스·주식의 임의 수치, 현재 없는 장소·메모·미읽음 알림 배지, 할 일·집중 시간 메뉴는 생성하지 않음.

## 변경하지 않은 제품 경계

- 기본 3탭(홈/일정/설정), 색상: 라이트 `#F7F8FA` / 다크 `#111315`, 차콜 `#23262B`, 평면 선형 아이콘.
- 로컬 일정 데이터는 외부 브리핑 요청에 전송하지 않음. 외부 요청에는 선택 정보만 전달.
- 다른 앱 알림 접근·민감 정보 권한 안내 및 직접 승인 후 일정 저장, 24건/48시간 보관 정책.
- 마이크는 명시적 시작 전 자동 녹음 금지. AI 요약·후보 재분석의 기기 지원/사용자 명시적 실행 조건 유지.
- API 29·35·36 자동 계측과 삼성 One UI 물리 기기 검증을 구분. GitHub CI 성공은 실제 마이크/위젯/AI 실기기 성공을 뜻하지 않음.

## QA 매트릭스 (완료 조건)

| 시나리오 | 확인 기준 |
|---|---|
| 로컬 일정 0건 | 다음 일정 없음·오늘 브리핑이 빈 상태를 올바르게 표시 |
| 로컬 일정 1건(오늘) | 다음 일정 카드에 1회, 오늘 일정에는 건수 설명만 표시; 상세/캘린더 진입 가능 |
| 로컬 일정 3건(오늘) | 다음 일정 카드의 1건을 오늘 리스트에서 중복 표시하지 않음; 남은 2건 시간순 |
| 다음 일정만 다음 날 | 오늘 일정이 있다면 전체 표시; 다음 날 일정은 다음 카드에 표시 |
| 일정 로딩/조회 오류 | AI 입력에 가짜 빈 일정 출력하지 않음; 오류·새로고침 유지 |
| 알림 접근 OFF | 전체 민감 권한 안내 및 설정 버튼 접근 가능; 자동 권한/자동 등록 금지 |
| 알림 추천 1/3/4건 | 승인/거절 및 추가 항목 설정 진입 유지 |
| 외부 정보 선택 0개 | 요청 버튼 대신 설정 이동 제공, 원격 요청 없음 |
| 선택했으나 서버 URL 미설정 | 서비스 미연결 안내, 원격 요청 비노출 |
| 선택했고 서버 URL 유효 | 사용자 직접 요청 시 조회; 오늘 날짜 결과만 렌더링; 실패 안내 |
| 화면/기기 | 라이트·다크, 소형 폰, 130/160/200% 큰 글꼴, 태블릿, TalkBack·터치 48dp |
