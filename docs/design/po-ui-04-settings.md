# PO-UI-04 · 설정 화면 리디자인

> 2026-11-05 · 2차 리디자인 4/8단계
> 디자인 기준: [Google Drive 설정 화면 가이드](https://drive.google.com/file/d/1g9xIHNQoOu4ukZpL_vcGXs5sBi88372r/view)

## 범위
- 기본/고급 탭, 테마/권한/알림/브리핑/위젯/기기 AI, 외부 정보 및 이전 일정 복구의 기존 기능을 보존하면서 설정 행을 재구성합니다.
- 실제 구현되지 않은 캘린더 계정 연동, 상시 음성 인식, 데이터 백업 기능이나 신규 탭은 추가하지 않습니다.

## 변경 사항
| 영역 | 변경 | 유지 기능 |
|---|---|---|
| 상단 | 브랜드 설명, 기본/고급 탭, 상태별 대비 정리 | 기존 2개 설정 구간 |
| 알림·아침 브리핑 | 아이콘·제목·설명·스위치, 시간 설정 접기/펼치기, 권한 상태 및 시스템 설정 바로가기 | 일정 알림, 매일 브리핑, 시간 값 유효성, Android 권한 요청 |
| 빠른 설정·위젯 | 긴 버튼 대신 이동형 행과 짧은 설명 | 타일 요청, 다음/오늘 일정 위젯 추가 |
| 기기 AI | Gemini Nano 지원 메시지는 읽기 전용 정보로 표기, 입력창 진입은 별도 동작 | 기기 지원 상태 조회, 음성은 명시적 시작만 허용 |
| 외부 정보 | 날씨·뉴스·주식 토글 요약, 도시/키워드/언어/종목은 필요 시 펼쳐 입력 | 기존 수동 외부 조회 방식, 설정 직렬 저장 |
| 이전 일정 | 원본 보존 안내와 복구 상태, 재시도 행 | Firebase 이전 데이터 복구 정책 |
| 화면 테마 | 시스템/밝게/어둡게 선택 라디오 및 상태 표현 | 저장된 테마 및 네이티브 빠른 입력 테마 동기화 |
| 개인정보 | 정책·문의 행, 데이터 보존 안내 | 기존 정책 URL과 지원 메일 링크 |

## UI 규칙
- 신규 UI 구성 요소는 src/components/settings/SettingsUI.tsx에 제한하고 기존 디자인 토큰/테마를 사용합니다.
- 상태와 스위치를 한 행에 배치하되 텍스트는 자연스럽게 줄바꿈합니다.
- 설정 행은 최소 56dp 이상, 한쪽 테두리나 그림자 없이 그룹 경계를 사용합니다.
- 자세한 편집만 접고 펼치며 실제 설정값은 사용자가 저장하기 전까지 변경하지 않습니다.
- 명시적 저장 성공·실패와 권한 요청 실패는 기존 앱 공통 확인 모달로 알립니다. 일반 토글 변경마다 성공 모달을 띄우지 않습니다.

## 회귀 방지
- 설정 저장, 설정값 복구, 알림 권한/정확한 알람 표시, 타일·위젯 요청, Gemini Nano 상태, 네이티브 빠른 입력 호출, 테마 모드, 개인정보 링크를 유지합니다.
- tests/ui-settings-stage4.test.mjs 및 기존 ui-design-system-stage1.test.mjs를 수정·추가했습니다.
- tools/ui/capture_android.py에 기본/고급 전환, 외부 정보 상세 확장, 다크 설정 캡처를 추가했습니다.
- 에뮬레이터, 접근성 및 큰 글꼴·회전·태블릿 검증의 한계는 최종 8단계에 별도 기록합니다.
