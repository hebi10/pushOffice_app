## 범위와 구현

- **CAL-01** 월간 달력과 선택 날짜/건수 요약을 **하나의 카드**로 결합. 중복된 별도 카드 테두리·상하 간격을 없애고 하단은 입력 버튼/날짜별 목록으로 즉시 이어짐.
- 날짜 표시 점은 실제 일정 건수(최대 3개)이며, 작은 화면에는 간단한 한 줄 안내만 표시. 스크린리더에는 기존 전체 설명을 접근성 레이블로 제공.
- **CAL-03** 선택 날짜 요약 오른쪽에 48dp 이상 터치 영역을 가진 **'목록' 이동 버튼** 추가. 사용자가 눌렀을 때 기존 `ScrollView`를 날짜별 일정으로 이동시키고 선택 날짜 정보 일부가 화면에 남도록 스크롤 높이를 조절. 자동 스크롤이나 불필요한 애니메이션은 도입하지 않음.
- 월 이동 시 이전 선택일을 유지하고 더 짧은 달은 말일로 제한. 예: 1월 31일 → 2월 28일, 윤년은 2월 29일. 날짜를 직접 탭하면 탭한 날짜를 사용. 현재 월·선택 날짜 표시 및 월별 Query 의존성 보존.
- **CAL-04** 기존 다중 점·색상·매월/매년 반복 발생 계산·시간순 일정 목록·종일/종료 시각·알림 배지·상세 이동·로딩/오류/빈 날짜 분기 그대로 유지.
- 스타일은 기존 Mono Office 라이트 `#F7F8FA`, 다크 `#111315`, 3탭, `uiSpacing`/`uiSizes.touchMinHeight`만 사용. 그라데이션/그림자·독립 신규 라이브러리는 추가하지 않음.

## 기능 구분

- **CAL-02 / `FUNC-12-02` 별도:** 현재 캘린더의 '빠른 일정 입력'은 `PushOfficeNative.openQuickEntry()`를 인자 없이 호출. 이 PR은 날짜 기본값 전달을 추가하지 않으며, 선택일이 자동 입력된다고 표시하지 않음.
- 네이티브 입력·음성·AI·SQLite 원본·일정 고유 ID·월말/윤년/DST·anchorZone·알림 재예약·업로드/서명 정책은 모두 불변.
- 앞선 홈 개선 PR #55는 Draft·미병합 상태로, 이 PR은 `main`을 기준으로 한 **독립 변경**. 병합 순서·추가 통합 QA는 별도.
