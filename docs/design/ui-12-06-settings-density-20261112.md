기준일: 2026-11-12 · 저장소 `hebi10/pushOffice_app` · 분기 기준 `main=731a7abe7690d945e80ed575edb2f15d0b981619`

## 완료 구현

### 기본 설정 (SET-01~05)

1. 기존 `기본 설정/고급 설정` 탭·알림·브리핑 시각·시스템 권한·위젯·알림 추천·기기 AI 구성을 유지한다.
2. 빠른 설정 타일의 조회 전 임시값을 `true`에서 `null`로 변경한다. 기기 조회 진행 또는 실패 시 사용 가능 상태를 추정하지 않는다. '확인 중'으로 표시하고 조작을 비활성화한다. 조회 성공 시에만 실제 사용 여부에 맞춰 스위치/버튼을 동작시킨다.
3. 다른 앱 알림 접근 권한이 아직 확인되지 않았을 때 `허용 필요`로 단정하지 않고 `확인 중`을 표시한다. 확인된 권한의 '허용됨/허용 필요'는 실제 네이티브 결과에 따른다.
4. 알림 분석 설정에서 긴 처리·보관 설명 2개를 기본 화면에 모두 펼쳐두지 않는다. **'최대 24건·48시간 / 승인 후 저장' 핵심 보관·동의 조건은 항상 표시**하고, 나머지 기기 내 규칙 분석·수동 AI 재분석·절전 및 백그라운드 제한 설명은 접근 가능한 '알림 분석 방식·기기 제한 안내' 행의 펼침 상태에 표시한다.
5. 민감 권한 동의 모달의 인증번호·금융 알림 안내, 직접 승인 전 일정 자동 저장 금지, 권한 철회·후보 삭제·서버로 알림 본문 미전송 고지는 기존 전체 문구를 그대로 유지한다.
6. 빠른 설정·위젯 도움말은 간결하게 정리하되 **타일 배치/위젯 설치 완료를 실제 조회 없이 확정 표시하지 않는다.**

### 고급 설정 (ADV-02~05)

1. 기존 외부 정보(날씨·뉴스·주식) 선택·도시·키워드·관심 종목 저장과 기본 꺼짐·명시적 네트워크 요청 정책은 변함없다.
2. 외부 정보 그룹 헤더에서 사용자 선택 종류 개수를 실제 설정값 기준으로 표시한다. `ENV.FUNCTIONS_BASE_URL`이 비어 있으면 **'외부 서비스 미연결 · 선택 N종 · 설정값만 저장'**, 값이 설정되었으면 **'요청할 때만 조회 · 선택 N종 · 일정 내용 전송 없음'**을 표시한다. 서버 URL이나 인증값 자체는 표시하지 않는다.
3. Firebase 레거시 가져오기는 해당 복구 기능으로만 표시한다. 새 로컬 일정의 JSON 백업/복원, Google·Microsoft 캘린더 연동, 보관 기간 자동 삭제, 저장공간 정리, 미지원 알림/홈 편집 옵션은 임의 추가하지 않는다.
4. '시스템/라이트/다크' 테마와 로컬 일정 삭제 위험 고지, 개인정보처리방침·지원 문의·AI/ML Kit 진단 고지는 그대로 보존한다.

### 공유 설정 컴포넌트

- 섹션 제목을 스크린리더의 `header`로 제공하고 줄임 기능 없이 가독성을 유지한다.
- 기존 설정 행의 장식 아이콘 구조는 보존하고, 토글은 제목과 설명이 함께 읽히게 한다.
- 그룹 아이콘과 제목 간 간격을 `uiSpacing.sm` → `uiSpacing.xs`로 줄이고, 실제 상태 배지의 최대 폭을 88 → 104dp로 조정해 큰 글꼴 줄바꿈을 허용한다. 최소 터치 높이 56dp는 유지한다.

## 비변경·보안 경계

- 사용자가 직접 부여/철회하는 Android 알림 권한, 백그라운드 후보 저장 정책, 누적 24건·48시간, SHA-256 AI 검증, Gemini Nano 다운로드·기기 AI 모델 관리, Native 빠른 입력·음성 명시적 시작, 로컬 SQLite 일정·알람/반복·Firebase 이전, 앱 테마·하단 3탭은 변경하지 않음.
- 기획 이미지의 가짜 설치 완료/알림 배지/모델 성능 수치를 실제 앱의 정적인 값으로 도입하지 않음.
- 앱 버전/패키지/서명 키/Play `1차 테스트` v1.1.0 코드 19의 상태를 변경하지 않음.
- PR #55(UI-12-02), #56(UI-12-03), #57(UI-12-04), #58(UI-12-05)은 Draft·미병합인 독립 작업이며 해당 파일을 임의 병합/변경하지 않음.
