## 원본 시안과 차이

- 원본은 아이콘·제목·짧은 설명·상태/토글을 조밀한 한 행으로 정리하며, 그룹 제목에 많은 설명을 중복하지 않습니다.
- 기존 Android 화면에서는 알림 첫 그룹이 한 화면을 거의 모두 차지하여 빠른 설정·위젯에 도달하려면 여러 번 스크롤해야 했습니다.
- 기존 모달은 48dp 아이콘과 제목이 수직으로 쌓여 제목·메시지·확인 버튼 사이 간격이 큽니다.

## 적용

1. 기본/고급 설정 전환 탭에 안내 아이콘을 추가하고 기존 선택 상태·48dp 터치 높이를 유지합니다. 신규 설정 탭은 만들지 않았습니다.
2. 기본 설정 3개 그룹과 고급 설정 '화면과 보관'에서 중복되는 그룹 설명만 제거했습니다. 직접 조회 조건처럼 중요한 외부 데이터 설명은 짧게 유지했습니다.
3. `SettingsUI`의 그룹 헤더와 목록 행의 세로 간격을 줄였습니다. 그룹 단위 경계, 라이트·다크 색상, 긴 텍스트 자연 줄바꿈, 최소 행 높이 56dp를 보존합니다.
4. 상태값(브리핑 시간·권한 허용 등)을 짧은 배경 배지로 표시하고, 읽기 보조 기능에 실제 상태값을 전달합니다. 상태는 기존 데이터에서만 읽으며 새 값을 추측하지 않습니다.
5. 공유 `AppDialog`는 아이콘(40dp)과 제목을 한 행에 정렬하고 패널 내부 여백을 축소했습니다. 화면 바깥 탭 닫기, 뒤로 가기, 메시지 스크롤, 위험 작업 색상, 취소/확인 버튼을 유지합니다.
6. 에뮬레이터의 기본 설정에서 '아침 브리핑 알림 시간' 편집을 열고 실제 저장 완료 모달을 캡처하는 두 장의 검증 이미지를 추가했습니다. 실제 사용자 일정·알림 데이터는 변경하지 않습니다.

## 기능 보존

- 설정 저장 및 실패 처리, 0~23시/0~59분 검증, 알림/정확한 알람, 홈 위젯 2종·타일, 기기 AI·음성 입력, 요청 기반 날씨/뉴스/주식, 이전 일정 복구, 기기 로컬 보관, 테마와 네이티브 테마 동기화, 개인정보 링크 유지
- 기존 홈/캘린더 화면, 디자인 토큰, Firestore 구조, Play 업로드 서명 및 작업 정책 변경 없음
