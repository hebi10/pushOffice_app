## 비교 결과

원본 시안은 입력 방식을 크게 고르는 바텀시트, 짧은 안내와 편집 도구, 제목·날짜·시간·반복 입력 그룹, 저장 버튼을 가장 중요한 최종 행동으로 제시합니다. 실제 4단계 Android 화면에서는 작은 일러스트, 긴 중복 안내 문구, 여러 보조 버튼, 높이가 큰 저장 전 확인 필드 때문에 특히 약 366dp의 작은 화면에서 저장 버튼 접근이 쉽지 않았습니다.

## 적용한 화면 보정

1. **입력 방식 선택:** 기존 접근 가능한 바텀시트의 2가지 선택과 닫기를 유지하고, 라이트 모드 일러스트를 140×106dp로 확장했습니다. 두 선택 카드의 최소 높이를 72dp로 올리고 제목·안내·카드 사이 간격을 조정했습니다. 다크 모드에는 기존처럼 흰 배경 이미지를 표시하지 않습니다.
2. **텍스트·음성 편집:** Android 중앙 다이얼로그와 키보드에 대응하는 스크롤은 그대로 두되, 헤더·설명·상태 영역·그룹 간격을 압축했습니다. '일정 내용' 필드와 음성/기기 AI 보조 액션을 유지하면서 중복 설명을 줄였습니다.
3. **주요 행동:** 직접 날짜·시간 지정과 뒤로 가기는 보조 행동으로, `내용 확인`을 편집 화면의 최종 주요 버튼으로 배치했습니다. 음성 시작은 명시적 사용자 클릭 때만 실행합니다.
4. **저장 전 확인:** 제목·날짜·시간 필드에만 `compact` 옵션을 적용하여 카드 내외 여백을 축소했습니다. 메시지·시간대·반복 선택, 날짜/시간 선택기, 변경 전·후 비교는 모두 유지했습니다. '입력으로 돌아가기'를 저장 버튼 위로 배치하여 `일정 저장`이 마지막 주요 버튼이 되도록 조정했습니다.
5. **작은 화면 확인:** 일반·약 366dp 좁은 화면에서 실제 확인 화면을 스크롤한 후 저장 버튼 접근이 가능한지 자동화 검증을 추가했습니다. 새 필수 캡처 2개를 등록했습니다.
