## 차이와 적용

| 비교 영역 | 기존 화면 | 보정 |
|---|---|---|
| 상단 헤더 | 시스템 네비게이션 제목 `Push Office / 일정 / 설정`만 표시 | 기존 `push-office-mark.png` 이미지 + `PushOffice` 텍스트를 모든 주 탭의 공통 헤더에 배치 |
| 알림 아이콘 | 없음 | 홈·캘린더 헤더에서 기존 **설정 화면**으로 이동하는 접근성 레이블 포함 버튼. 새로운 알림함·미확인 알림 배지 미구현 |
| 브랜드 중복 | 화면 상단 타이틀과 본문 `PUSH OFFICE` 문구 중복 | 본문 보조 문구를 화면별 `로컬 일정 비서 / 날짜별 일정 / 환경 설정`으로 분리 |
| 본문 도입부 | 최소 104dp, 일러스트 104x88dp | 도입부 88dp, 일러스트 88x74dp로 축소하고 짧은 설명·제목·브랜드의 높이 균형 조정 |
| 타이포그래피 | 화면 제목 26/34, 헤더 17, 컴포넌트별 세부 차이 | 화면 제목 25/32, 브랜드 18/24로 통일. 섹션·본문의 기존 글꼴과 터치 크기 유지 |
| 상단/섹션 여백 | 화면 상단 20dp, 공통 간격 14dp | 상단 12dp, 공통 간격 12dp |

## 기존 동작 및 기획 유지

- 3개 주요 탭(홈·일정·설정) 유지. 보존 라우트 `briefing`, `chatHistory`는 숨긴 채 사용 가능
- 일정 생성·변경·삭제, 로컬 데이터, 알림, 위젯, AI, 캘린더와 설정 저장 로직 변경 없음
- 네이티브 QuickEntry UI 및 Android 시스템 권한창을 변경하지 않음
- 시안의 할 일·집중 시간·AI·프로필 탭을 새로 추가하지 않음
- 미포함 Pretendard 파일을 추가하지 않고 기존 Android/iOS 시스템 글꼴 유지
- 미확인 알림 개수를 나타내는 배지는 데이터 근거가 없어 추가하지 않음
- Play 내부 테스트 기본 자동 배포 정책 및 서명 설정 변경 없음

## 검증 기준

1. `npm test`, `npm run typecheck`, ESLint, Expo Android 번들 내보내기
2. Kotlin 단위 테스트·Android 디버그 빌드
3. 홈·캘린더·설정·일정 상세·네이티브 입력 등 기존 에뮬레이터 34장 필수 캡처, warnings=0
4. 특히 홈·캘린더·설정에서 새 헤더 로고/텍스트, 겹치는 글자, 다크 모드 대비와 콘텐츠 상단 간격을 실제 캡처로 검토
5. 전체 검증 통과 후 PR을 `main`에 squash 병합
