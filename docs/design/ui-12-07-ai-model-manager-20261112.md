## 화면별 상세 수정

1. **목록 로딩/오류 정합성** — 네이티브 `listAiModels()` 조회 전 '확인 중', 성공한 경우에만 사용 준비 모델 수(실제 0~5종), 실패 시 명확한 재조회 버튼과 '이전 결과일 수 있음' 표시. 실패를 무한 로딩이나 설치 불가로 단정하지 않는다. 이전 조회 상태에서는 설치·삭제·검증·추론·기본 모델 선택을 비활성화한다.
2. **다운로드 상태** — 네이티브 조회값(`bytesDownloaded`/`totalBytes`)이 모두 유효할 때만 0~100% 진행률과 실제 내려받은 MB를 표시하고, 보조 진행률 표시를 스크린리더용 진행 바와 연결. 총 파일 크기를 확인할 수 없으면 '진행률 확인 중'으로 표시하며 'Wi-Fi 대기'를 추정하지 않는다. 실제 네이티브 `model.message`(일시 정지·오류·기기 미지원·검증 중)를 보조 문구로 그대로 제공한다.
3. **무결성 검사** — SHA-256 전체 파일 검사는 기존 `PushOfficeNative.verifyAiModel()` 버튼과 `AiModelDownloadStore.verifiedInstalledFile()` 경계를 그대로 사용한다. Gemini Nano 파일은 시스템 AICore가 관리하므로 앱 파일 검사/삭제 버튼을 제공하지 않는다.
4. **한국어 일정 추론 테스트** — 기존 한국어 일정 문장을 모든 준비된 모델에 순차 실행. 현재 사용자 입력과 모호한 과거 응답이 섞이지 않도록 수정 버전(`sampleRevision`)을 부여해 입력이 바뀌면 이전 결과를 삭제하고 이미 실행 중인 구 결과도 화면에 반영하지 않는다. 모델 설치/삭제/선택/검증 행동을 시작하면 해당 모델의 이전 테스트 결과를 무효화한다. 네이티브 모델 상태가 설치/사용 가능한 상태가 아니면 기존 결과도 무효화한다.
5. **실측 결과 표시** — 실패 응답의 인위적인 `0ms` 측정값을 노출하지 않는다. 성공 결과라도 제목/시간/반복값이 누락된 경우 '미확인/확인 필요'로 표기하고 1970년의 가짜 날짜를 표시하지 않는다. 실제 측정된 시간이 있는 경우에만 ms 표기. 반복 결과는 '반복 없음/매월/매년' 한국어 안내. 결과는 모델 테스트 버튼 아래, 기본 모델 선택 버튼 위에 위치한다.
6. **기본 선택** — 기본 모델 전환은 준비된 모델 중 **현재 입력으로 테스트 성공이 확인된 모델**에만 활성. `selectAiModel()` 내부 재검증과 SHA-256·AICore 지원 여부 검사는 그대로 유지. 기기에서 모델을 기본으로 선택했다는 상태는 '현재 사용 중'의 추론 진행 표현이 아니라 '기본 선택됨'으로 명확하게 구분한다.
7. **모델 삭제** — LiteRT-LM 모델에만 삭제/중지·삭제를 허용하며 기존 삭제 확인창을 유지. 삭제한 기본 모델은 Gemini Nano로 선택 값이 돌아갈 수 있지만 해당 기기가 Nano를 지원하지 않으면 텍스트 입력을 사용해야 한다는 안내를 추가. 일정 데이터는 변경하지 않는다.
8. **페이지 레이아웃** — 화이트/중성 회색/차콜 및 다크 테마, 공통 카드/버튼/48dp 터치 토큰 유지. 모델 설명/라이선스·출처는 기존 접기/펼치기로 유지, 리스트 상태·모델별 상태·실측값만 우선 노출. 추가 의존성·모의 성능 데이터·장식 효과 없음.

## 보안과 기능 변경 금지

- 승인된 다운로드 원본(Hugging Face HTTPS), 서버의 등록 SHA-256 검사, DownloadManager(사용자 요청/Wi-Fi), 앱 사설 저장 폴더, 전체 파일 체크섬 및 모델 추론 전 재검증, 손상 감지·선택 초기화 로직은 Kotlin 코드 **수정하지 않음**.
- 사용자가 직접 승인·저장한 일정, 로컬 SQLite 일정 원본, 시간대·월/연 반복, 민감 알림 사전 동의/후보 승인, 텍스트·음성 입력, AI 자동 전송 금지, 앱 버전·서명·Google Play 트랙은 **변경하지 않음**.
- Gemini Nano·ARM64 실제 실행 성공, 다운로드 4종 실기기 파일 무결성, 기기별 성능/메모리 측정은 이번 화면 코드만으로 PASS 판정하지 않는다.
- 기존 독립 Draft PR #55(UI-12-02 홈), #56(UI-12-03 달력), #57(UI-12-04 네이티브 입력), #58(UI-12-05 상세), #59(UI-12-06 설정) 미병합. 이 PR은 최신 `main`에서 독립 분기하며 자동 병합하지 않는다.
