# Push Office — Mono Office 10-D 화면별 정밀 디자인

기준일: 2026-11-08. 대상: PR #42 통합 Draft (10-A~10-F).

## 변경한 화면

**홈**: 핵심 CTA '일정 빠르게 추가' 다음에 실제 다음 일정을 배치했습니다. 선택형 알림 접근 안내·후보·AI 브리핑·오늘 일정·외부 정보 조회의 동작은 보존했습니다. 다음 일정의 한쪽 장식 레일을 제거하고 입력 윤곽선 기반의 전체 경계로 표현합니다. 브리핑 건수는 큰 칩 대신 보조 텍스트로 간결화했습니다.

**캘린더**: 월간 달력과 선택 날짜 일정 목록을 잇는 요약 표시의 가짜 버튼 형태를 제거하고 `accessibilityRole="summary"`를 적용했습니다. 날짜 선택/월 이동/실제 1~3개 일정 표시점/로딩·오류·빈 상태/빠른 입력을 유지했습니다.

**설정**: 기본·고급 탭의 선택 배경/전체 경계를 중성 색으로 바꾸었습니다. 펼친 시간 설정과 외부 정보 설정의 중첩 배경을 제거하고 저장 성공 메시지에 체크 아이콘을 추가했습니다. 알림 접근 사전 고지와 동의, Gemini Nano 다운로드, 위젯, Firebase 이전 데이터 복구 등의 기존 작업 흐름은 불변입니다.

**일정 상세**: 상단 요약 서피스를 10-C 표면 및 테두리와 일치시켰습니다. 시작 시각·종료 날짜/시간·반복·알림을 구분하고 종료 날짜를 한국어 형식으로 표기합니다. 종일 일정은 종료 시각을 별도로 드러내지 않습니다. 저장·반복 확인·재알림·삭제 확인과 연결 데이터는 그대로 유지했습니다.

## 변경 파일과 검증

- 화면: `app/(tabs)/index.tsx`, `calendar.tsx`, `settings.tsx`, `app/schedule/[id].tsx`.
- 기존 이전 단계 테스트 2개가 가정하던 장식 레일 및 정보 순서 기대값을 실제 10-D 기획에 맞게 변경했습니다.
- 신규 `tests/ui-mono-office-stage10d.test.mjs`는 화면 순서, 캘린더 접근성, 설정의 상태·저장, 일정 상세의 저장/삭제 기능 경로를 확인합니다.
- GitHub Actions에서 Node 테스트, 타입 검사, ESLint, Expo Android 번들, Kotlin 단위/Debug APK, Android 캡처를 별도로 검증합니다. 실행 중인 CI를 성공으로 간주하지 않습니다.
- Android의 앱 권한·AI·데이터 처리 코드는 변경하지 않았으며 새로운 기능·라이브러리·폰트·애니메이션은 추가하지 않았습니다.
