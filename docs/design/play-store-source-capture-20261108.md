# Push Office · Google Play 설명 이미지 제작 전 원본 캡처 준비

## 목표
스토어용 설명 이미지의 원본이 되는 실제 Android 화면을 **고해상도**로 확보합니다. 이 단계에서는 앱 UI를 다시 그리거나 가공된 스토어 이미지를 생성하지 않습니다.

- 실행 환경: Android API 29 에뮬레이터, Asia/Seoul (+0900), 1080×1920, density 400
- 실제 앱 내 테스트 데이터: Team meeting, Design review, Workout / 저장 확인용 Client meeting
- 기존 57장 QA 캡처와 별도 보관: `ui-captures/store-source/`
- Android 앱 소스/일정 저장 동작/Play 배포/알림·음성 기능 변경 없음

## 제작시 유의
스토어용 그래픽에는 **실제로 구현된 기능만** 표기합니다. Google Play의 실제 앱 사용 경험을 보여주는 정책을 따르며, 캡처 안의 일정명과 UI를 가짜로 생성하거나 임의로 변경하지 않습니다. 스크린샷 촬영은 일회용 에뮬레이터에서만 이루어지며 개인 실제 일정이나 계정에는 접근하지 않습니다.

기준 Play 등록정보의 기존 6장 이미지는 초기 구현 기반이므로 실제 촬영 원본 검증 전 교체하지 않습니다.
