# PO-UI-06 · 일정 상세·수정·모달 리디자인

> 2026-11-05 · 2차 리디자인 6/8단계
> 계획 기준: Google Drive PushOffice 리디자인 8단계 작업계획

## 작업 범위

기존 로컬 일정 상세 화면의 입력·선택·확인 작업을 더 쉽게 찾을 수 있도록 디자인만 정리했습니다. 스토리지·알림·반복 일정 계산·데이터 마이그레이션·외부 호출은 변경하지 않습니다.

| 영역 | 적용 | 기존 동작 |
|---|---|---|
| 상세 헤더 | 공통 ScreenIntro, 상태별 일정 조회 메시지 | 기존 상세 라우트 및 ID |
| 기본 정보 | 제목 입력 전용 카드 | 기존 제목 저장 |
| 날짜와 시간 | 공통 SchedulePickerField(시작/종료 날짜·시간), 종일 토글, 종료 시간 제거 | 기존 입력 값 및 날짜·시간 적용 |
| 반복과 알림 | 선택된 반복 옵션 강조, 설명과 토글 계층 정리 | 매월/매년 반복 및 알림 설정 |
| 저장 | 주동작 버튼 분리, 반복 일정 확인 AppDialog 유지 | 저장 실패 안내 및 반복 시 전체 수정 확인 |
| 재알림 | 기존 10분 뒤 알림/취소를 별도 그룹으로 분리 | native snoozeSchedule / cancelSnooze |
| 삭제 | 위험 동작 분리, 기존 destructive AppDialog 유지 | 전체 반복 삭제, 취소, 실패 처리 |
| 날짜·시간 선택창 | 공통 PickerDialog로 너비·색상·텍스트·스크롤·뒤로·키보드 동작 통일 | 달력/시간 선택, 취소 및 적용 |
| 없는 일정·로딩 | 상태별 안내, 목록으로 돌아가기 | 불필요한 데이터 변경 없음 |

## 디자인 규칙

- 기존 primary, onPrimary, surface, text, border 토큰을 사용하며 별도 테마·폰트·의존성을 도입하지 않습니다.
- 각 선택 필드는 터치 영역 50dp 이상, 긴 텍스트 줄바꿈 및 내부 스크롤을 고려합니다.
- 모달 최대 너비 440dp, 높이 88%, 전체 테두리·여백을 공통 AppDialog와 통일합니다.
- 키보드 사용을 위해 KeyboardAvoidingView 및 ScrollView를 사용하고 시스템 뒤로 가기/닫기/취소를 유지합니다.
- Android OS 고유의 날짜·시간·권한 시스템 창은 교체하지 않습니다. 3단계에서 개선한 네이티브 입력창의 앱 자체 다이얼로그는 그대로 보존합니다.
