# UI-11-03 — 달력·일정 목록 리디자인

기준: Google Drive 「Push Office｜초기 기획 vs 최신 Android 화면 비교 분석 및 UI-11 단계별 개선 계획」, 2026-11-11.

## 구현 범위
- 월간 달력 헤더 글꼴을 소폭 줄여 월간 그리드의 정보 밀도를 개선했습니다. 날짜 탭·월 이동·스와이프 동작은 변경하지 않았습니다.
- 날짜 선택 안내를 제공하고, 선택 날짜·실제 일정 건수를 하나의 중립 패널로 묶었습니다.
- 빠른 일정 입력과 날짜별 일정 카드 사이의 간격을 공통 간격 토큰으로 정리했습니다.
- 로딩·오류·일정 없음·1건·3건과 같은 실제 데이터 상태는 기존 분기를 유지합니다.
- 종일 일정, 시작·종료 시간, 매월·매년 반복, 알림 아이콘, 상세 이동, 다중 점 표시는 기존 ScheduleItem/일정 조회를 그대로 사용합니다.

## 안전 범위
- 일정 원본·SQLite·반복 발생 계산·알림·날짜/시간대·앱 버전·하단 탭을 변경하지 않습니다.
- PR #47(빠른 입력)과 PR #48(홈)과 별개 브랜치에서 작업합니다.
- 기존 화면 기획의 월간 그리드/카드 개선 중 **5주·6주 달, 작은 화면, 130~200% 글꼴**의 실제 캡처와 물리 기기 검증은 아직 완료가 아닙니다.

## QA 게이트
1. Node 회귀 테스트, TypeScript, ESLint, Expo Android export 통과.
2. Android UI 실캡처, 1·3건 날짜 목록, 소형/다크/130%/태블릿 확인.
3. 기존 UI-11-01·02 병합 이후 최신 main에 재기반하여 충돌과 통합 회귀 검사.
4. 모든 필수 검증 이후 Draft 해제/병합. 현재 브랜치에서는 AAB/Play 트랙을 수정하지 않습니다.
