# UI-11-05 — 기기 AI 모델 관리 화면 리디자인

기준: Push Office Google Drive 「초기 기획 vs 최신 Android 화면 비교 분석 및 UI-11 단계별 개선 계획」 중 AI-01~03.

## 변경 사항
- 각 모델의 실제 상태를 상단에 배치하여 준비됨, 설치 전, 설치 가능, 다운로드 중, 무결성 검사 중, 기기 미지원, 오류를 한글 텍스트로 구분합니다.
- 모델 엔진 및 추정 용량을 간단히 보이고 설명·라이선스는 접근 가능한 펼침 영역에 표시하여 목록의 정보 밀도를 낮춥니다.
- 다운로드·재시도, SHA-256 검증, 실제 추론 테스트, 테스트 성공 후 기본 모델 선택, 삭제 확인, 모델 출처 링크는 기존 동작을 유지합니다.
- 결과 화면은 실제 실행 시간과 파싱 결과만 표시하며 모델 정확도·성능을 사전에 보장하지 않습니다.

## 비변경
- Gemini Nano(AICore), Qwen3 0.6B, Qwen3.5 0.8B/2B, Gemma 4 E2B 모델 정의/다운로드 API/검증 및 설치 파일 무변경.
- 사용자 승인 없는 다운로드 금지, 테스트 중 일정 자동 저장 금지, 손상된 모델의 정상 표시 금지.
- 일정/알림, 파일 삭제 처리, 키, Android 패키지, Play 트랙/버전 변경 없음.

## 남은 게이트
1. Node 전체 회귀·TypeScript·ESLint·Expo Android export와 Kotlin 빌드.
2. Android 화면 캡처 19a/19b 및 소형/130%/다크/태블릿 화면 상태·스크롤 접근성 검수.
3. 지원되는 실제 Android ARM64 기기의 5종 모델별 파일 다운로드/원격 SHA-256 검증/추론/성능 비교/삭제·복구.
4. PR #47~#50의 순차 병합 후 최신 main 기준 재검증 및 최종 QA.
5. 전부 확인 전 Draft 유지, main 및 Google Play 배포 보류.
