# FUNC-12-02 — 캘린더 선택 날짜 → 네이티브 빠른 입력 기본값

기준일: 2026-11-16 / 저장소: hebi10/pushOffice_app / 신규 Play 배포 없음.

## 문제와 변경 범위
캘린더에서 날짜를 선택해도 "빠른 일정 입력" 버튼이 인자 없는 native `openQuickEntry()`를 호출하여, 사용자가 선택한 날짜를 입력 화면에서 다시 지정해야 했습니다.

- `calendar.tsx`의 선택 상태(`YYYY-MM-DD`)를 `openQuickEntryForDate(selected)`로 직접 전달합니다.
- 기존 홈, 위젯, Android 빠른 설정 타일의 `openQuickEntry()`와 음성 전용 입구는 변경하지 않습니다.
- Android 모듈은 엄격한 ISO `LocalDate`만 수락합니다. epoch milliseconds로 바꾸지 않아 사용자의 시간대 경계에서 하루가 바뀌는 문제를 방지합니다.
- Native chooser/editor에 선택 날짜를 안내하고, 직접 입력/파서 실패 확인 화면의 날짜 칸에만 기본값을 표시합니다. **시간은 자동 설정하지 않습니다.**
- 사용자가 "11월 20일", "2026-11-20", "내일", "금요일", "매월 20일" 등 문장에 날짜를 쓴 경우 선택 날짜보다 명시적 날짜를 우선합니다.
- 날짜가 없는 "오후 3시 치과 예약" 같은 입력은 캘린더 선택 날짜를 적용한 뒤, 변경 가능한 3단계 확인 화면을 거칩니다.
- 잘못된 명시적 날짜(예: "2월 30일")는 캘린더 선택 날짜로 조용히 대체하지 않습니다. 사용자가 직접 날짜/시간을 확인해야 합니다.
- 사용자가 AI 모델을 직접 실행하는 경우에도 결정론적 파서가 검증한 날짜·시각과 AI 출력이 일치해야 승인 단계로 진행합니다. 서로 다르면 결과를 거부합니다.
- 기본 저장 동작(사용자 확인 → Native SQLite → 알림 예약)은 그대로이며, 자동 저장·음성 녹음·권한 부여·모델 다운로드는 발생하지 않습니다.
