# Push Office 정밀 보정 · 2단계 홈·브리핑·일정 카드

> 기준: 2026-11-06 · Google Drive 홈·브리핑 시안(02)과 Android 29 실제 에뮬레이터 캡처 34장
> 선행: [정밀 보정 1단계](./precision-ui-stage1-header-20261106.md) / PR #14

## 확인한 차이

- 시안은 '빠른 일정 추가 → 짧은 브리핑 → 다음 일정 → 오늘 일정' 순서로 첫 화면을 압축하지만, 기존 화면은 브리핑 출처가 별도 행으로 늘어지고 카드 간 세로 공간이 큼.
- 다음 일정 항목은 배경색만 강조되어 시안처럼 시간과 제목의 경계가 선명하지 않음.
- 오늘 일정 행은 캘린더 목록보다 같은 정보가 시각적으로 덜 정돈되어 있음.

## 적용 범위

- 기존의 홈 섹션 순서 및 텍스트·음성 입력 CTA, 로컬 일정·날짜·시간·반복·알림·상세 진입 동작 그대로 유지.
- 홈의 브리핑/다음 일정/오늘 일정 카드에만 재사용 가능한 선택형 compact 간격을 적용. 다른 화면의 일반 카드와 모달 디자인은 유지.
- 브리핑의 출처 안내를 요약 본문과 묶어 빈 공간을 축소. 기기 AI 버튼은 기존처럼 실제 사용 가능할 때만 노출.
- 다음 일정 항목 내부에 기존 브랜드 파란색 강조 레일을 추가하고 68dp 최소 높이로 압축. 긴 제목 2줄, 날짜·종일·종료시간·반복 정보는 그대로 유지.
- 기본 일정 목록 행에 동일한 브랜드 레일 및 조밀한 세로 여백 적용. 캘린더 변형 행의 기존 높이는 유지.
- 실제 일정이 없는 경우 가상의 할 일·집중 시간·장소를 추가하지 않으며, 전체 오늘 일정 목록을 임의로 자르지 않음.

## 자동 검증

- `npm test`, `npm run typecheck`, ESLint, Expo Android 번들, Kotlin 단위 테스트·앱 빌드
- 실제 에뮬레이터: 홈 기본/일정 존재/다크 화면 및 기존 34장 캡처, 경고·이미지 누락 0건
- UI 정밀 보정 2단계 회귀 테스트: 섹션 순서, 요약 중복 방지, 일정 상세 이동, 기존 로컬 AI·수동 외부 브리핑 보존
- 기기별 글꼴 확대, 태블릿, 위젯 설치 및 음성·기기 AI 실사용은 자동 캡처만으로 확정하지 않음.
