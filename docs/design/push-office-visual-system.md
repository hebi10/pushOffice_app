# Push Office 디자인 기준

## 목표
로컬 일정 비서의 기본 동작인 **빠른 입력, 일정 확인, 상세 수정**을 일관된 정보 구조로 제공합니다.
기존 일정 저장·알림·반복·AI 기능과 라우팅 동작은 그대로 유지합니다.

## 공통 규칙

> 2차 디자인 시스템 1단계의 상세 값·컴포넌트 예시는 [PO-UI-01](./po-ui-01-shared-system.md)을 기준으로 합니다.
> 2026-11-08 신규 **Mono Office 10-A** 컬러 규격은 [10-A 세부 가이드](./mono-office-stage10a-20261108.md)를 우선합니다. 기존 UI 규칙의 기록은 아래와 같으며 10-A에서는 RN 테마와 위젯 컬러 XML만 통일했습니다. 브랜드 이미지·네이티브 입력창/타일의 전체 스타일은 10-B~10-E 단계에 남아 있습니다.
- 주요 동작 `primary`: 라이트 `#23262B` / 다크 `#E7E9EC`. 텍스트 `onPrimary`는 각각 `#FFFFFF` / `#111315`입니다.
- 브랜드 블루 `brandAccent`: 라이트 `#2563EB` / 다크 `#93C5FD`. UI 전체 배경이 아닌 브랜드의 작은 영역에 제한합니다.
- 라이트: 배경 `#F7F8FA`, 카드 `#FFFFFF`, 글자 `#1C1E21`, 테두리 `#DDE1E5`.
- 다크: 배경 `#111315`, 카드 `#1C1F22`, 글자 `#F5F6F7`, 테두리 `#3B4046`.
- `primaryLight`는 선택·강조의 중성 보조 표면이며, 기능 오류/성공은 `danger` / `success` 시맨틱 색으로만 구분합니다.
- 일정 삭제는 `destructive` / `onDanger`를 사용하며 일반 보조 동작과 분리합니다.
- 텍스트 크기: 주요 화면 제목 26, 카드 제목 17, 본문 15~16, 보조 텍스트 12~14.
- 여백: 화면 좌우 16, 카드 내부 16, 주요 버튼 최소 높이 48~50.
- 입력창 및 모달: `AssistantTextField`, `SettingRow`, `AppDialog` 등 공통 컴포넌트 우선, 시스템 권한 허용창 등 OS가 소유한 UI는 그대로 유지합니다.

## 폰트
현재 릴리스에 Pretendard 라이선스 폰트 파일은 포함되어 있지 않습니다.
실제로 설치 가능한 Android/iOS 시스템 글꼴을 `APP_FONT_FAMILY`로 사용합니다. 저장된 폰트 선호값을 유지하며, 글꼴 파일이 미설치된 경우 대체 글꼴을 표시합니다.
임의의 파일 또는 타사 폰트를 추측해 번들에 넣지 않습니다. Pretendard 추가는 추후 별도 라이선스 자산 확보 후 진행합니다.

## 화면
- 하단 탭: 홈, 일정, 설정. 설계 포스터에 그려진 미구현 탭(할 일, AI)을 임의로 추가하지 않습니다.
- 일정 상세/수정: 날짜·시간 모달 및 반복·삭제 확인창을 공통 디자인으로 유지합니다.
- 빠른 입력: Android 네이티브 편집기 및 변경 대상 선택/모델 다운로드 확인 UI에 동일 팔레트를 사용합니다.
- 구형 브리핑/채팅 기록 라우트: 기존 기록 및 공유 기능을 유지하되 헤더/타이포그래피/여백을 공통화합니다.
- 홈 위젯: 라이트/다크 리소스 팔레트, 2개 위젯 간 동일한 버튼·카드 규칙을 사용합니다.
- 사용자 테마 설정(시스템/밝게/어둡게)은 Android 네이티브 빠른 입력창에도 동기화합니다. 위젯은 시스템 다크 모드를 따릅니다.

## 검증
`ui-validation.yml`에서 TypeScript, ESLint, 기존 Node 회귀 테스트, Android Kotlin 검사 및 디버그 빌드를 확인합니다.
`ui-screenshots.yml`의 에뮬레이터 캡처는 실제 화면을 보여주지만 기기별·OS별 모든 시각적 문제를 증명하지는 않습니다.
Play 테스트 트랙 배포와 시각 검증은 별도 단계로 판단합니다.
