## 사용자 흐름과 적용 범위

| 단계 | 기존 UX | 이번 정합성 수정 |
|---|---|---|
| 1 / 3 입력 방식 선택 | 네이티브 바텀시트에서 텍스트/음성 택일 | 현재 140×106dp 브랜드 일러스트, 접근성 선택 행과 400dp 폭 상한 보존, 단계 안내 텍스트만 추가 |
| 2 / 3 일정 내용 작성 | 텍스트 입력 + 상태 + 접이식 음성/AI 도구 + 본문 아래 '뒤로/내용 확인' | 단계 안내와 수동 날짜·시간 바로가기 설명 구체화, **'뒤로'·'내용 확인'을 ScrollView 밖 고정 하단**으로 이동. 키보드 및 큰 글꼴에서도 CTA 접근 |
| 3 / 3 저장 전 확인 | 제목·한국어 날짜 요약·날짜/시간 선택기·고급 ISO 필드·월/연 반복·고정 저장/돌아가기 | 단계 안내 추가, 날짜·시각이 없을 때 안내를 오류색으로 표시하고 접근성 실시간 공지 유지. 기존 저장/취소/변경 대상/검증 로직 불변 |

## 구현/안전 원칙

- 기존 `QuickEntryActivity.kt` 내 화면(사용자 명시적 선택 → 내용 작성 → 검토 후 저장)을 유지. React Native 화면 또는 탭을 신규 생성하지 않음.
- 저장 전에는 **절대 일정 자동 등록 금지**. `ScheduleSerial.withLock`, 이전 기록 일치 검사, 중복 저장 방지, `ScheduleTime.validate`, 원본 anchorZone/기존 종료 시각·반복 및 후보 승인 정책 불변.
- 음성 입력은 선택만으로 녹음하지 않음. 기기 내 음성 모델/마이크 권한은 '음성 입력 시작'을 직접 누를 때만 처리. 지원하지 않는 기기에서는 텍스트 입력 계속 사용.
- AI 도구는 접힌 상태를 기본으로 하고, 사용자가 직접 누를 때만 추론. 실패·취소 시 사용자가 작성한 텍스트 보존.
- 동일한 모노톤 Light `#F7F8FA`, Dark `#111315`, Surface `#FFFFFF/#1C1F22`, 차콜 `#23262B`, 아웃라인·평면 스타일과 50dp 버튼/48dp 터치 영역 보존.
- 본 작업에 추가하지 않은 기능: `매일/매주 반복`, `처음 입력 시 종료 시각`, `장소·회의 링크·메모`, `캘린더 선택 날짜를 빠른 입력 기본값으로 전달`, `시작 N분 전 알림`. 모두 별도 데이터/네이티브·알림 설계 필요. 기존 제공처럼 화면에 그리지 않음.
- 기존 Draft PR #55 홈/브리핑, PR #56 캘린더와 독립된 브랜치/파일 변경. PR 순차 병합 전 전체 통합 QA 필요.
