## 시안 대조

- 시안은 달력이 화면의 탐색 도구이고 '선택 날짜 요약 → 빠른 입력 → 독립된 일정 카드'가 바로 이어지는 구조입니다.
- 기존 Android 화면에서는 88dp 소개 영역의 일러스트, 넓은 주별 달력 행간, 64dp 선택 날짜 카드와 카드 안에 카드가 겹치는 목록 때문에 첫 화면에서 일정을 확인하기 어렵습니다.
- 시안의 할 일·AI·프로필 5탭, 임의 회의실·장소·회의 데이터는 기존 앱의 승인된 기능 범위가 아니므로 추가하지 않습니다.

## 변경 사항

1. 캘린더 화면에서만 `ScreenIntro compact`를 사용하여 브랜드 헤더와 본문 사이의 높이를 축소하고 캘린더 소개 일러스트를 제거했습니다. 기존 다른 화면의 소개 레이아웃은 변경하지 않습니다.
2. `react-native-calendars` 공식 테마 스타일 재정의를 통해 월간 주별 여백을 축소하고, 월 이동·날짜 선택·6주 표시가 필요한 월의 달력 기능은 보존했습니다.
3. 일정 존재 표시 점은 원본 실제 일정 건수에 따라 1~3개를 사용하고 파랑·초록·노랑을 다크 모드에 맞게 구분합니다. 선택 날짜의 점 대비는 `onPrimary`를 유지합니다.
4. 선택 날짜와 실제 일정 건수를 한 줄로 압축했습니다. 조회 중/조회 오류 상태는 숫자로 위장하지 않으며, 접근성 레이블은 보존합니다.
5. `AssistantCard flat`을 일정 목록에서만 사용하여 이중 카드 테두리와 중복 여백을 없앴습니다. 각 `ScheduleItem`은 독립된 카드로 유지하며 시간·제목·종일·반복·알림·상세 이동 동작은 변경하지 않습니다.
6. 하단 빠른 일정 입력 버튼은 기존 네이티브 `openQuickEntry`를 그대로 호출합니다.
