# PO-UI-07 · 보존 화면·위젯의 디자인 정리

> 2026-11-05 · Push Office 2차 리디자인 7/8단계
> 참조: Google Drive PushOffice 리디자인 8단계 작업계획

## 적용 범위

- `app/(tabs)/chatHistory.tsx`: 공통 화면 여백·타이포그래피 토큰 적용, 취소·수정 버튼의 최소 높이 48dp, 스크린리더 레이블·관련 메시지 힌트 추가, 목록 로딩 실패 시 재조회 동작을 갖춘 오류 화면 추가. 기존 메시지 목록·일정 수정·알림 취소·일정 삭제 처리 유지.
- `app/(tabs)/briefing.tsx`: 생성·재생성·새로고침·공유·복사 동작을 유지하면서 접근성 레이블과 최소 터치 크기 정리. 다크 모드 주요 액션의 텍스트 색을 하드코딩된 흰색 대신 테마의 `onPrimary`로 통일.
- `modules/push-office-native/android/src/main/res/values-night/colors.xml`: Android 위젯 2종의 배경·문구·주동작·테두리·입력 배경을 앱 다크 테마 색상과 일치. 화면 크기별 데이터 표시·기존 위젯 클릭 PendingIntent 로직·레거시 위젯 XML 구성은 변경하지 않음.
- `tests/ui-legacy-widgets-stage7.test.mjs`: 저장·취소·공유·복사 동작의 연결과 색상·터치·접근성 회귀 보호.

## 보존 범위

- 하단 탭 3개 유지, 숨겨진 이전 화면의 기존 라우트 유지.
- 브리핑 생성과 저장된 결과, 채팅 내역, 일정 CRUD, 알림, Android 홈 위젯 기존 사용 경로 보존.
- 신규 이미지·아이콘·폰트·라이브러리·백엔드 기능 추가 없음.
- 런처·스플래시·기존 브랜드 이미지는 사용자 승인 없이 교체하지 않음.
- Play 빌드·배포·서명 정책 변경 없음.

## 검증 및 잔여 제한

- 필수 자동 검사: Node 테스트, TypeScript, ESLint, Expo Android 번들, Kotlin 단위 테스트, Android 디버그 빌드.
- Android 라이트/다크 기본 캡처 및 홈·설정·일정·네이티브 입력 회귀는 기존 CI 캡처 워크플로 활용.
- 위젯의 실제 홈 화면 배치·다양한 위젯 크기·큰 글꼴·태블릿·제조사 런처별 클릭 동작과 보존 라우트의 모든 화면 상태는 **8단계 실화면 QA에서 별도 확인 필요**. 코드/리소스 검증만으로 이 항목을 완료로 표시하지 않음.
- 스토어 설명용 이미지는 실제 화면 자료와 별도 검수/승인이 필요하므로 이번 PR에서 수정하지 않음.
