# PO-UI-05 · 월간 캘린더 및 일정 목록 리디자인

> 2026-11-05 · 2차 리디자인 5/8단계
> [일정·캘린더 디자인 가이드](https://drive.google.com/file/d/1B991jN4U5iWiPdBcXZ5q0FbIQqlaYTjb/view)

## 화면 정보 계층
1. 월간 캘린더: 월 이동, 날짜 선택, 일정 존재 여부
2. 선택 날짜 요약: 날짜와 등록된 일정 건수
3. 빠른 일정 입력: 기존 Android 네이티브 입력창
4. 해당 날짜의 일정: 실제 발생 일정만 시간순 카드 목록

## 적용 및 범위
- 기존 react-native-calendars의 월 이동 및 날짜 선택 인터랙션을 유지하면서 드래그 월 이동을 지원합니다.
- 실제 월별 조회 결과에서 날짜별 일정 건수를 계산하고 한 날짜에 점 최대 3개로 표시합니다. 3개 점은 3건 이상을 의미합니다.
- 선택 날짜는 기존 primary/onPrimary 토큰으로 강조하고, 다크 모드에서도 선택 날짜와 점의 대비를 유지합니다.
- 날짜/건수 요약 카드, 빠른 입력 CTA, 개별 일정 목록의 스캔 순서를 정리합니다.
- 일정 항목은 달력에서만 별도 카드 변형(시간, 최대 3줄 제목, 반복/알림, 상세 이동)을 사용하고, 홈 카드의 기존 정보 배치는 그대로 보존합니다.
- 종일 일정, 종료 시간, 달을 넘기는 종료 시각, 긴 제목, 반복 발생 시각 등 기존 표시 정보를 보존합니다.
- 로딩/조회 오류/선택 날짜 0건을 별도로 표시하고, 선택한 월과 날짜의 일관성을 유지합니다.
- 실제 위치·장소·지도 정보가 데이터 모델에 없으므로 가이드의 장소 예시는 재현하지 않습니다.
- 기존 일정 저장, 데이터 모델, 반복 투영 함수, 알림 설정, 네이티브 빠른 입력, GitHub Actions/Play 배포 설정은 변경하지 않습니다.

- 기존 테스트: 홈·브리핑 ScheduleItem 사용자 동작 유지.
