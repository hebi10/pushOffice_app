## 적용 범위

| 항목 | 적용 |
|---|---|
| 중립 디자인 | 10-A의 라이트/다크 시맨틱 컬러를 재사용하며 그라데이션·그림자 미추가 |
| 공통 라운드 | Field 6dp / Button 8dp / Card 10dp / Dialog 10dp |
| 공통 치수 | 좌우 16dp, 카드 패딩 16dp, 버튼 높이 50dp, 터치 높이 48dp 유지 |
| `AssistantCard` | 라이트·다크 서피스, 윤곽선, 보조 아이콘 색, 제목 접근성 헤더 유지 |
| `AssistantButton` | Primary=차콜/밝은 회색, Secondary=서피스/윤곽선, Destructive=위험색. Disabled=중립 보조면/보조 글자. Busy=실제 색상과 스피너, 중복 누름 차단 |
| `AssistantTextField` | 입력면·테두리 시맨틱 역할 통일, 기존 편집·키보드·입력 길이·접근성 레이블 유지 |
| `SettingRow`, `SettingsUI` | 행 아이콘의 불필요한 배경 제거, 그룹 헤더를 같은 서피스로 통일, 선택 라디오/토글/상태 텍스트 유지 |
| `AppDialog` | 중립 검정 오버레이, 보조 버튼의 입력 테두리, 위험 확인 버튼의 별도 의미색, 스크롤·취소·뒤로가기 유지 |
| `ScreenIntro` | 제목·소개·일러스트 배치 유지, 아이브로우 보조색과 이미지 모서리 통일 |
| `AppBrandHeader` | 기존 10-B 브랜드 마크와 설정 이동·44/48dp 터치 영역 유지, 보조 아이콘 톤 통일 |

## 디자인·접근성 기준

- 카드와 설정 그룹에 그림자, 광택, 그라데이션, 불필요한 라벨 칩을 추가하지 않습니다.
- 일반 텍스트·버튼 대비 4.5:1 이상, 주요 인터랙티브 컨트롤 경계 대비 3:1 이상을 10-A의 테마와 교차 검사합니다.
- 라디오 선택은 `checked`, 버튼은 `disabled/busy`, 그룹 제목은 `header` 등 상태와 의미를 시맨틱·텍스트로 함께 전달합니다.
- 입력 폼·일정 저장·삭제·알림 권한·로컬 AI·Firebase 데이터·위젯·Google Play 설정은 수정하지 않습니다.
- 새 라이브러리·폰트·다른 탭·기능·애니메이션을 추가하지 않습니다.

## 회귀 검증

- 신규 `tests/ui-mono-office-stage10c.test.mjs`: 공통 토큰, 명암 대비, 상태, 모달 상호작용, 브랜드 보존 확인.
- 기존 `npm test`, `npm run typecheck`, ESLint, Expo Android 번들, Kotlin 단위·디버그 빌드, 에뮬레이터 UI 캡처의 실제 CI 결과를 후속 확인합니다.
- 10-B의 직전 Android 최종 검증도 완료 여부를 별도로 확인합니다. 선행 배포 미완료를 완료로 기록하지 않습니다.

## 남은 단계와 병합 정책

- **10-D** 홈·캘린더·설정·일정 상세 화면의 정보 구조·밀도·세부 인터랙션 점검.
- **10-E** Kotlin 네이티브 빠른 입력·위젯·빠른 설정 타일의 테마 및 클릭 QA.
- **10-F** 라이트/다크, 작은 화면, 130% 폰트, 태블릿, 실제/모의 일정 및 권한 등 전체 검증.
- 별도 실기기 수동 검사(One UI 런처, 알림 접근/철회, Gemini Nano 실제 다운로드/추론) 및 Google Play 비공개 alpha 국가 타기팅 해결은 디자인 QA와 분리.
- 최종 통합 검증이 끝나기 전 `main` 병합과 Play 업로드를 진행하지 않습니다.
