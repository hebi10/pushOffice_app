# UI-11-04 — 설정·일정 상세·공통 모달 리디자인

기준: Google Drive Push Office UI-11 비교·개선 계획의 SET-01~04, DETAIL-01~03.

## 작업
- 기본/고급 설정 그룹 구조는 유지하고 길고 반복되는 기능 설명을 요약형으로 압축합니다. 알림 권한 상태와 5종 모델의 실제 상태, 설정 항목은 기존 실데이터를 유지합니다.
- 일정 상세 상단 요약의 여백을 줄이고, 제목 수정·반복/알림·재알림·삭제 섹션을 명확하게 표기합니다. 삭제는 기존 위험 버튼과 되돌릴 수 없음 안내를 유지합니다.
- 공통 AppDialog 긴 안내문 스크롤과 버튼의 장문 가독성을 보완하고 삭제 행동의 접근성 힌트를 추가합니다. 모달 취소·삭제·확인 로직은 변경하지 않습니다.
- Node 회귀 테스트를 추가했습니다.

## 비변경
- SQLite, 일정 원본, 시작/종료 시각·반복 발생 계산, 알림 예약, 후보 승인, 앱 권한, AAB, 버전/트랙 등 무변경.
- 민감 알림 정보 고지와 자세한 설명, 반복 일정 전체 수정 및 삭제 확인 메시지는 유지합니다.
- UI-11-01/02/03은 별도 Draft PR이며 이 브랜치는 main을 기점으로 작성했습니다.
