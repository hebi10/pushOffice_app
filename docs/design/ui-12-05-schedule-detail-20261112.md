## 기능 경계

- `DETAIL-01`: UI 구현. 단지 정보 위계·반응형 레이아웃 개선.
- `DETAIL-05`: 데이터 무결성 보존. 날짜/시간 검증, 반복 전체 수정 확인, 실제 삭제·재알림 API 호출 변경 없음.
- `DETAIL-02/03`: **별도 기능 개발**. 장소·회의 링크·메모, 매일·매주 반복, 일정 유형/업무 분류는 `ScheduleRecord` 및 SQLite/파서/알림/백업 데이터 계약에 없음. 이 PR은 해당 기능을 임의 추가하지 않음.
- 홈·캘린더·빠른 입력 PR #55·#56·#57은 Draft로 남아 있는 독립 개발물. 이 PR은 최신 `main`에서 분기되며 해당 PR들의 파일·기능을 수정하거나 병합하지 않음.
- 디자인: Mono Office 화이트·중성 회색·차콜·다크/라이트 의미색 유지. 새 라이브러리·그라데이션·그림자·과도한 radius 추가 없음. 하단 3탭 동일.

## QA 목록

1. **정보** — 제목 2줄/긴 제목, 시작·종료가 같은 날/다른 날, 종일, 종료 없음, 0/1/다수 일정, 매월·매년 반복 및 알림 ON/OFF의 상태 일치.
2. **폼** — 시작/종료 날짜·시간 선택 및 분 숫자 입력 오류, 종료 시간 제거, 종료가 시작보다 빠른 경우 저장 거부, 일정이 삭제됐거나 로딩·조회 오류인 경우 복구 경로.
3. **반복·알림** — 반복 안 함/월/년 선택 상태, 큰 글꼴 줄바꿈, 반복 전체 수정 확인, 10분 뒤 재알림 및 취소, 연결된 알림 삭제와 삭제 취소.
4. **가독성** — 360dp 소형 화면, 5~7인치 일반폰/태블릿, 가로/세로·키보드, 시스템 글꼴 100/130/160/200%, TalkBack/48dp 이상 터치.
5. **자동** — 동일 PR HEAD의 `npm test`, TypeScript, ESLint, Expo Android 번들, Kotlin 디버그 및 Android API29 에뮬레이터의 11-schedule-detail/12/13/14/17a/11a 등 캡처, `capture-manifest.json` warning 0.
6. **병합** — PR #55~57 의존성/병합 순서 및 현재 `main` 업데이트 후 통합 회귀·최신 캡처 재검증. 실제 삼성 One UI/AI 기기 결과는 증빙 없으면 미검증.
7. **배포 금지** — `1차 테스트`의 코드 19는 이 PR에서 건드리지 않으며, 최신 AAB 업로드·테스터 설치·Play API 트랙 승격은 별도 릴리스 단계.
