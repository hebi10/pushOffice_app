## 적용한 변경

HOME-01 — 인사·실제 날짜·보조 설명을 한 번에 묶고 기존 달력 이미지를 홈 히어로에서 확대합니다. 다른 화면은 기존 ScreenIntro 규격을 유지합니다.

HOME-02 — 기존 '일정 빠르게 추가'를 주요 버튼으로 유지하고, 기존 네이티브 voice 편집기에 직접 진입하는 명시적 보조 행동을 제공합니다. 녹음은 별도로 시작 버튼을 누를 때만 수행됩니다.

HOME-03 — 브리핑에 실제 첫 일정의 시간·제목, 개수 배지를 표시합니다. 0건 배지와 중복된 오늘 일정 빈 목록 카드를 숨깁니다. 로딩·오류 상태는 보존합니다.

HOME-04 — 다음 일정의 유효한 종료 시각·날짜·반복·상세 이동 기능을 유지합니다. 존재하지 않는 장소·회의실 등은 표시하지 않습니다.

HOME-05 — 오늘 일정이 있는 날 모든 카드를 시간순으로 표시하고, 두 번째 건수 문구와 외부 브리핑 상위의 중복 제목을 제거합니다. 외부 정보는 기존처럼 명시적 요청에서만 조회합니다.

HOME-06 — 독립된 Android 에뮬레이터에 실제 로컬 일정 1건/3건을 넣은 홈 화면 2장을 추가 캡처합니다. 사용자 데이터에 쓰지 않습니다.

## 보호 범위

저장 구조·반복·알림·일정 상세 탐색·Gemini Nano의 가용성 판단·외부 데이터 네트워크 정책·기존 하단 3탭을 변경하지 않습니다. 시안에만 존재하는 할 일·집중 시간·위치·미구현 신규 탭은 추가하지 않습니다.

## 완료 조건

Node·TypeScript·ESLint·Expo Android·Kotlin 검사, 실제 에뮬레이터 기존 50장과 신규 2장 필수 캡처, 경고 0건, 빈 홈/1건/3건 실제 디자인 비교, PR squash main 병합, Play 내부 테스트 실제 게시 단계 별도 확인.
