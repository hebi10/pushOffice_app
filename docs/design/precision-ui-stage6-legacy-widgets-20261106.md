## 코드·시안 비교

1. **보존 브리핑:** 공통 브랜드 헤더 아래 이전 브리핑 화면에 별도 88dp 소개부가 유지되고, 새로고침 및 하단 액션 영역의 여백이 일반 화면보다 큼.
2. **채팅 기록:** 구형 채팅의 시간 표시가 10sp로 작고, 본문/빈 상태가 새 공통 토큰과 다른 텍스트 규격을 사용함.
3. **Android 위젯 2종:** 두 위젯 모두 텍스트·음성 버튼 색과 시각적 중요도가 동일함. 일반 빠른 입력에서는 텍스트를 주요 버튼으로 사용하는 원본 규칙과 다름.
4. **브랜드:** React Native 헤더의 PushOffice와 위젯의 PUSH OFFICE 문자열 표기를 통일할 필요가 있음. 별도의 원본 아이콘·이미지 파일에 대한 승인된 변경 요청은 없음.

## 적용

- 보존 브리핑과 채팅에 재사용 `ScreenIntro compact`를 적용하고 내용의 줄바꿈·액션 영역·시간 표시 간격을 조정.
- 채팅 기록의 데이터와 액션은 그대로 유지. 실제 앱에 없는 상시 AI 채팅을 약속하던 빈 상태 문구를 기록 안내로 교정.
- 두 위젯에서 텍스트 입력을 브랜드 블루 주요 버튼, 음성을 보조 버튼으로 구분. 기존 48dp 높이, 텍스트/음성 접근성 레이블, 일정 상세·빠른 입력 PendingIntent 연결 보존.
- 위젯 라이트 `#2563EB / #FFFFFF`, 다크 `#5B9FE6 / #121212`의 텍스트 대비를 회귀 테스트에 포함.
- 위젯의 라벨을 공통 헤더와 동일하게 `PushOffice`로 맞추고, Kotlin 측 헤더 너비 측정에도 같은 문자열 적용.
- 기존 앱 아이콘·적응형 아이콘·단색 아이콘·스플래시·favicon의 경로 및 이미지 파일을 자동 감사. **이미지 콘텐츠 자체는 교체하지 않음**.
- Android 29 에뮬레이터에서 숨겨진 `briefing`과 `chatHistory` 라우트를 기존 커스텀 스킴 딥링크로 직접 진입해 실제 화면을 필수 캡처. 기존 38장에 2장 추가.

## 기존 기능 유지

- 홈·일정·설정 3탭, 레거시 기록 조회·브리핑 재생성/복사/공유, 일정 취소·수정·알림 제거, 로컬 데이터 저장, 위젯 2종의 기존 클릭 경로, 외부 정보 요청 정책.
- 새 네트워크 API·Firebase 스키마·파일 기반 자산·라이브러리·알림/저장 로직 추가 없음.
- 플랫폼이 관리하는 런처·시스템 권한창·제조사별 위젯 렌더링 동작 변경 없음.

## 검증 및 남은 제한

- Node 테스트·TypeScript·ESLint·Expo Android JS 번들, Kotlin 단위 테스트·디버그 APK.
- 실제 Android 에뮬레이터: 40장 화면 캡처, 필수 이미지 누락·경고 0건, 보존 두 라우트 딥링크 실행.
- Android 위젯은 XML·리소스·Kotlin 빌드·연결 회귀 검사. **제조사 런처에 실제 배치·크기 변경·클릭·큰 글꼴 시험은 7단계 실기기 검증 대상**이며 이번 자동 화면 캡처 성공만으로 완료 처리하지 않음.
- 실물 이미지 자산·스토어 그래픽 교체는 승인되지 않은 범위로 제외.
- 전체 검사 완료 후 `main` squash 병합, Google Play 게시 단계는 별도 결과 확인.
