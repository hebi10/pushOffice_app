Push Office 개인정보 처리 안내

초안 작성일: 2026년 11월 3일 · 시행일: 미정
검토 대상: Android 앱 com.hebi96.pushOffice_app, 버전 1.1.0(버전 코드 3)

Push Office는 한국어 일정 입력, 일정 알림, 홈 위젯과 오늘의 브리핑을 제공하는 앱입니다. 새 설치에서는 로그인이나 새 계정 생성 없이 기기에 일정을 저장합니다. 선택한 외부 브리핑 서비스와 Google ML Kit의 진단 정보 처리는 아래와 같이 별도로 설명합니다.

1. 기기에 저장하는 정보

일정의 기준 저장소는 앱의 로컬 SQLite 데이터베이스입니다. 일정 제목, 날짜·시간, 시간대, 반복 및 알림 설정, 생성·수정 시각, 일정 입력 원문(sourceText)을 저장합니다. 음성 인식으로 입력한 경우 인식된 텍스트가 이 원문에 포함될 수 있습니다.

앱 설정, 브리핑 기록, 이전 버전의 기록과 가져오기 상태는 기기의 앱 저장소에도 보관됩니다. 앱은 기기 내 기록을 구분하기 위한 무작위 식별자(UUID)를 만들어 저장합니다. 이 식별자는 외부 브리핑을 요청할 때도 포함됩니다. 기본 일정 입력·확인·수정·알림은 외부 브리핑 없이 사용할 수 있습니다.

2. 음성 입력과 마이크

음성 입력은 사용자가 입력 창에서 시작 버튼을 누를 때만 시작하며 마이크 권한이 필요합니다. 앱은 지원되는 Android 기기의 한국어 기기 내 음성 인식을 사용하고, 지원되지 않으면 텍스트 입력을 안내합니다. 앱 코드에는 녹음 파일을 저장하거나 음성을 외부 서버로 전송하는 기능이 없습니다. 입력 창을 떠나거나 앱이 비활성화되면 인식을 중지합니다.

기기에 한국어 음성 모델이 없으면 시스템 음성 인식 서비스에 모델 다운로드를 요청할 수 있습니다. 모델의 제공·다운로드와 기기 지원 여부는 시스템 서비스에 따릅니다. 마이크 권한을 허용하지 않아도 텍스트로 일정을 입력할 수 있습니다.

3. 기기 AI와 Google 진단 정보

지원 기기에서 Gemini Nano와 Google ML Kit GenAI를 사용해 일정 입력을 해석하거나 일정 요약을 만들 수 있습니다. ML Kit 공식 설명에 따르면 입력 내용과 생성 결과의 처리는 기기에서 이루어지고 해당 내용과 결과는 ML Kit에 의해 Google 서버로 전송되지 않습니다.

이와 별도로 ML Kit는 진단 및 사용 분석을 위해 기기·앱 정보, 사용자·기기 또는 기타 식별자와 설치 식별자, 지연 시간 등 성능 지표, API 설정, 입력·출력의 크기, 기능 버전, 초기화·다운로드 등의 기능 이벤트, 오류 코드, 설정된 언어 정보를 처리할 수 있습니다. 입력·출력의 크기는 입력 내용이나 생성된 문장 자체와 구별됩니다.

현재 앱은 홈과 설정 화면에서 기기 AI의 준비 상태를 자동으로 확인하며, 이 SDK 경로의 진단 정보 처리를 끄는 앱 내 설정은 제공하지 않습니다. Google 공식 안내는 이 진단 정보에 HTTPS를 사용하고 ML Kit가 이를 제삼자에게 전달하지 않는다고 설명합니다. 이 설명은 앱의 모든 외부 통신에 대한 보증을 뜻하지 않습니다.
